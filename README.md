# Logistics Shipment MIS & Document Verification Tracker

An Excel project that turns raw shipment and document data into daily, weekly and monthly MIS reports, with built-in data checks.

> All data in this project is fictional sample data.

## Screenshots
![Dashboard](screenshots/dashboard.png)
![MIS Report](screenshots/mis-report.png)

## What it does
- Shipment Data: dropdown-based entry, auto lookups for route, rate and delivery time, and a per-row Data Check.
- Doc Verification: status tracking, aging (Overdue / Within SLA) and completeness checks.
- MIS Report: choose Daily, Weekly or Monthly and a date to rebuild all figures.
- Data Quality: counts duplicates, blanks and invalid entries, and shows accuracy %.
- Dashboard: KPI cards and charts for freight, on-time delivery and document status.

## Excel skills used
VLOOKUP, INDEX-MATCH, IF, COUNTIF/COUNTIFS, SUMIFS, AVERAGEIFS, Data Validation, Conditional Formatting, Charts
